# Changelog

All notable changes to NoctiCycle. Versions follow [Semantic Versioning](https://semver.org/);
while the version is `0.x`, the command-line options may still change between minor versions.

## 0.1.0 - first release

- Full-year lunar calendar as a single, self-contained HTML file: phases, illumination, moon age,
  exact new, quarter and full moon times, optional rise/set times and illumination sparklines.
- Interactive day cards, today highlight, next-events banner, responsive layout and light/dark theme.
- Night-sky phase band that follows the moon's illumination.
- One-page landscape print layout (`--print-format`) with paper, style and layout options.
- Automatic timezone detection, hemisphere-aware moon icons, `.ics` calendar export.
- Cultural layers, combinable: lunar traditions (`--tradition`: Māori, Hindu, Wiccan), moon names
  (`--moon-names`: Anishinaabe, Wiccan, Almanac, Celtic tree, Chinese lunar months) and year wheels
  (`--wheel`: Wicca, Druid, Slavic, East Asian solar terms, Heathen).
- Linux release builds: a folder build (`.tar.gz`) and an AppImage, with the ephemeris bundled.
